### Brain Tumor Classification using Deep Learning
*Research Intern @ SR University — under Prof. Sallauddin.Md · May 2025 – Oct 2025* &nbsp; [![GitHub](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white)]([LINKS])

- Engineered and benchmarked **four deep learning architectures** — CNN, VGG15, MobileNetV2, ResNet50 — for MRI-based brain tumor classification, achieving **88.8% test accuracy** with Precision/Recall/F1 ≈ 0.88 across all classes.
- Applied **transfer learning** via VGG15 and MobileNetV2 for feature extraction and model generalization, running a systematic trade-off analysis between accuracy and computational efficiency.
